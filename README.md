# saving-favorite

推し活をする者のための金銭管理アプリ。

ログイン後のHOMEから左メニューで画面を切り替えます。

- HOME：月カレンダー、推し一覧、初期状態で閉じたカテゴリ別の所持グッズ。
- 日程管理：期間付きのイベント・コラボ、推しとの関連付け、メモ、開始・終了の事前通知。
- 金銭管理：購入予定・支払い済み・所持グッズ、数量、購入期限、月額・年額の会費、月別集計、推し別予算と残額。
- 推し一覧／推しの登録：複数の推しの登録・編集・削除、月予算の設定。
- 所持グッズ登録：カテゴリ別の登録・編集・削除。金銭管理と同じデータを使い、二重計上を防ぎます。
- 推しの登録／アカウント設定：画像をPNG・JPEG・WebP・GIFから選び、アップロード前に正方形の切り抜き範囲を拡大・縮小・ドラッグで調整できます。プロフィール画像も同じように設定できます。

左メニューはJavaScriptで開閉し、CSSのtransitionでスライドします。狭い画面では背景タップ・Escapeキーでも閉じられます。OSの「動きを減らす」設定ではアニメーションを停止します。

データは実行ディレクトリの `data/saving-favorite.mv.db` に保存します。以前のメモリDBの内容は引き継がれません。今後の登録データは再起動後も保持されます。DBファイルはGit管理対象外です。

通知はアプリ内のお知らせと、許可されたブラウザー通知です。画面を閉じた状態のプッシュ通知やメール送信は未実装です。購入期限は3日前から、イベントは設定した日数前から通知します。ストアURLはリンクの保存に対応し、商品名・価格の自動取得は未実装です。

定期支払いは登録開始日から毎月／毎年、同額を計上します。未来の日付は支払予定として集計します。実際の決済と連動したものではありません。月末に該当日がない場合は末日に計上します。

## 動作確認

Java 17以上とMavenでSpring Bootを起動します。テストは普段使うDBとは別のDBで実行してください。

```powershell
.\mvnw.cmd spring-boot:run "-Dspring-boot.run.arguments=--server.port=18081 --spring.datasource.url=jdbc:h2:file:./target/app-test-db"
pwsh -NoProfile -File scripts/smoke-test.ps1
```

スモークテストはテスト用アカウントを作り、自動ログイン、各データの保存・編集・削除、入力検証、CSRF保護、ユーザー間の分離を確認します。
